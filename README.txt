QUICKEST WAY TO PUBLISH
1. Unzip the package.
2. Upload the contents of the folder to your web host's public web/root folder.
   Common names are public_html, www, htdocs, or the folder assigned to your domain.
3. Make sure index.html is directly inside that web/root folder.
4. Visit your domain and refresh.

No WordPress, database, plugins, or build process are required.
The site is a basic responsive static website and should work on nearly any host.

TO EDIT TEXT
Open index.html in a plain-text editor and change the visible wording.
To change colors, edit the values at the top of styles.css:
--blue: #0D1A63;
--orange: #DF301C;
